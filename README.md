###  [Smart Legal Assistance](https://github.com/yuktha2005/smart-legal-assistance)

AI-powered legal document assistant built around **Hybrid RAG**
for document retrieval and context-aware question answering.

**Highlights**
- 📄 Multi-PDF processing and document retrieval
- 🔎 Semantic search using FAISS and BM25
- 🧠 Context-aware conversational Q&A
- 📚 Source citations and confidence scoring
- 🔐 Authentication and session management
- 🗄️ MySQL database integration
- 🐳 Docker & Docker Compose deployment
- 🔊 Offline Piper TTS support

**Tech:** Python · Streamlit · Ollama · Qwen3 · Hybrid RAG ·
FAISS · BM25 · MySQL · Docker

- 🌡️ Temperature, pressure, vibration and load analysis
- 🤖 XGBoost-based failure prediction
- 📊 Machine learning model comparison
- 🔍 SHAP-based explainable AI
- ⚙️ Flask API for prediction
- 📈 Risk-factor identification

**Tech:** Python · Flask · Scikit-learn · XGBoost · SHAP ·
Pandas · NumPy · HTML · CSS · JavaScript
